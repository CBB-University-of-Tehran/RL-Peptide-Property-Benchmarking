## 📌 Overview

This repository contains the **code, benchmarking workflow, sensitivity analysis, and analysis outputs** associated with the manuscript:

> **Reinforcement Learning in Peptide Design: A Systematic Review and Original Property-Based Benchmarking Analysis of Generated Sequences**

The project provides a **reproducible property-based benchmarking and sensitivity-analysis framework** for comparing peptide sequences generated by **reinforcement learning (RL)** and **RL-inspired methods** against natural peptide reference sets.

The analysis focuses on six key physicochemical properties:

| Property | Description |
| --- | --- |
| **Sequence length** | Number of amino-acid residues |
| **Molecular weight** | Estimated peptide molecular mass |
| **GRAVY** | Grand average of hydropathicity |
| **Isoelectric point (pI)** | Sequence-based estimate of the pH at which the peptide has zero net charge |
| **Net charge at pH 7.0** | Estimated peptide charge under physiological-like conditions |
| **Aliphatic index** | Relative contribution of aliphatic side chains |

Generated peptides are evaluated across four major categories:

* 🦠 **Antimicrobial peptides (AMPs)**
* 🧩 **MHC-binding peptides**
* 🔄 **Cyclic / macrocyclic peptides**
* 🧪 **Mixed / other peptide sets**

## 🔬 Benchmarking Workflow

The notebook performs complementary property-based benchmarking and sensitivity analyses.

### 1️⃣ Literature-Range Compliance

Generated peptides are evaluated against **literature-derived physicochemical ranges** relevant to their peptide category.

For each applicable property, compliance is reported as:

> **Percentage of generated sequences falling within the applicable literature-derived range**

This analysis provides an intuitive measure of whether generated peptide sets fall within broadly expected physicochemical ranges.

---

### 2️⃣ Distributional Comparison with Natural Peptides

Generated peptide distributions are compared against natural peptide reference distributions using multiple complementary statistical and distance-based metrics:

* **Descriptive statistics**
* **Mann–Whitney U test**
* **Kolmogorov–Smirnov test**
* **Normalized Wasserstein distance**
* **Percentage of generated values within the natural 5th–95th percentile interval**

These analyses are performed at two levels:

* **Individual model level**
* **Generation-strategy level**

This allows both model-specific and broader methodological trends to be evaluated.

---

### 3️⃣ Feature Contribution Analysis

To quantify the relative influence of each physicochemical property on the composite distributional-distance score, the contribution of each feature is calculated from the six equal-weight normalized Wasserstein components.

For each model:

> **Feature contribution (%) = individual normalized Wasserstein distance / sum of the six normalized Wasserstein distances × 100**

This analysis is descriptive and does **not introduce feature-importance weights** into the ranking procedure.

---

### 4️⃣ Leave-One-Feature-Out Sensitivity Analysis

Ranking sensitivity is evaluated using a **leave-one-feature-out** procedure.

The baseline composite score is first calculated using all six physicochemical properties. The ranking is then recalculated six additional times, each time temporarily excluding one property.

For each leave-one-feature-out scenario:

* one feature is omitted,
* the composite score is recalculated as the **arithmetic mean of the remaining five features**,
* model rankings are recomputed, and
* changes relative to the six-feature baseline are recorded.

This analysis is used to determine whether model rankings are disproportionately dependent on any single physicochemical property.

> **No generative model retraining and no feature reweighting are performed during this analysis.**

## 🧪 Physicochemical Property Calculation

Physicochemical properties are calculated from peptide primary sequences using Biopython-based sequence analysis.

### pI Calculation

Sequence-based pI values are calculated using Biopython's `charge_at_pH()` ionization model together with a bisection search over an extended **pH range of 0–14**.

This extended search avoids numerical lower- and upper-bound effects associated with the narrower default pI search interval while retaining the same underlying sequence-based ionization model.

The calculated pI values should therefore be interpreted as **sequence-based estimates**, particularly for peptides whose topology or chemical modifications alter terminal ionization behavior.

---

## ✅ Sequence Quality Control

To ensure consistent and reproducible physicochemical calculations, only sequences composed entirely of the **20 standard proteinogenic amino acids** are retained for quantitative analysis.

Sequences containing:

* non-canonical residues,
* unsupported amino-acid symbols, or
* otherwise invalid sequence characters

are **excluded from benchmarking in their entirety** and logged for traceability.

This quality-control step prevents invalid residues from introducing inconsistencies into physicochemical property calculations.

---

## 🌿 Natural Reference Sets

Natural peptide reference sets contain **100 sequences per primary peptide category** and were derived from established peptide databases:

| Peptide Category | Reference Database |
| --- | --- |
| Antimicrobial peptides | **APD6** |
| MHC-binding peptides | **IEDB** |
| Cyclic / macrocyclic peptides | **CycPeptMPDB** |

Equal-sized, quality-filtered reference subsets were used to provide a standardized basis for comparison across peptide classes.

Reference sequences were **not selected on the basis of the six benchmarked physicochemical properties**, reducing the risk of artificially shaping the reference distributions toward a desired benchmarking outcome.

## ▶️ Running the Notebook

The benchmarking notebook is designed primarily for use in **Google Colab**, but can also be executed in a compatible local Jupyter environment.

### Steps

1. Open `RL-Peptide-Property-Benchmarking.ipynb` in Google Colab.
2. Run the notebook cells sequentially.
3. Upload the requested FASTA files when prompted.
4. Allow the workflow to:

   * validate peptide sequences,
   * calculate physicochemical properties,
   * calculate sequence-based pI values using the extended pH search,
   * perform literature-range compliance analysis,
   * perform statistical comparisons against natural reference sets,
   * calculate normalized Wasserstein distances,
   * rank models and generation strategies,
   * calculate feature-level contributions,
   * perform leave-one-feature-out sensitivity analysis,
   * generate distribution and ranking plots, and
   * export the final HTML benchmarking report.

> **FASTA header requirement:**  
> For generated peptide datasets, FASTA headers should identify the **model** and **peptide type** according to the format expected by the notebook.

## 📊 Statistical Notes

Please consider the following points when interpreting the benchmarking results:

* Statistical tests are performed only for groups containing **at least three sequences**.
* Reported **p-values are unadjusted for multiple comparisons** and should therefore be interpreted as exploratory.
* Model-level comparisons represent the **available or reported generated sequence sets**, rather than complete model-output distributions.
* Composite normalized Wasserstein distance scores use the six physicochemical properties with **equal weighting**; no additional feature-importance coefficients are introduced.
* Leave-one-feature-out analyses are **sensitivity analyses only** and do not involve retraining any generative model.
* Empirical compliance and normalized Wasserstein distance are complementary but independently calculated metrics and should not be interpreted as interchangeable measures of similarity.
* For cyclic peptides, sequence-based pI and net-charge calculations assume **ionizable N- and C-termini** and do not explicitly model head-to-tail cyclization, terminal modifications, or other topology-dependent structural constraints.
* Broad literature-defined physicochemical ranges are intended as descriptive reference ranges and do not necessarily reflect category-specific natural distributions.

## 📈 Interpretation of Rankings

The framework reports two complementary forms of model-level comparison:

* **Empirical compliance**, based on the percentage of generated values falling within the natural-reference 5th–95th percentile intervals.
* **Composite normalized Wasserstein distance**, based on the average normalized distributional distance across the six physicochemical properties.

Higher empirical compliance indicates greater overlap with the central range of the natural reference distribution, whereas lower normalized Wasserstein distance indicates greater overall distributional similarity.

Because these metrics quantify different aspects of similarity, a model may rank differently depending on which criterion is considered.

The sensitivity analysis additionally evaluates whether these rankings remain stable when individual physicochemical properties are temporarily excluded.
