## 📌 Overview

This repository contains the **code, benchmarking workflow, and analysis outputs** associated with the manuscript:

> **Reinforcement Learning in Peptide Design: A Systematic Review and Original Property-Based Benchmarking Analysis of Generated Sequences**

The project provides a **reproducible property-based benchmarking framework** for comparing peptide sequences generated by **reinforcement learning (RL)** and **RL-inspired methods** against natural peptide reference sets.

The analysis focuses on six key physicochemical properties:

| Property                   | Description                                                  |
| -------------------------- | ------------------------------------------------------------ |
| **Sequence length**        | Number of amino-acid residues                                |
| **Molecular weight**       | Estimated peptide molecular mass                             |
| **GRAVY**                  | Grand average of hydropathicity                              |
| **Isoelectric point (pI)** | Estimated pH at which the peptide has zero net charge        |
| **Net charge at pH 7.0**   | Estimated peptide charge under physiological-like conditions |
| **Aliphatic index**        | Relative contribution of aliphatic side chains               |

Generated peptides are evaluated across four major categories:

* 🦠 **Antimicrobial peptides (AMPs)**
* 🧩 **MHC-binding peptides**
* 🔄 **Cyclic / macrocyclic peptides**
* 🧪 **Mixed / other peptide sets**

## 🔬 Benchmarking Workflow

The notebook performs **two complementary benchmarking analyses**.

### 1️⃣ Literature-Range Compliance

Generated peptides are evaluated against **literature-derived physicochemical ranges** relevant to their peptide category.

For each property, compliance is reported as:

> **Percentage of generated sequences falling within the applicable literature-derived range**

This analysis provides an intuitive measure of how closely generated peptide sets conform to expected physicochemical characteristics.

---

### 2️⃣ Distributional Comparison with Natural Peptides

Generated peptide distributions are compared against natural peptide reference distributions using multiple complementary statistical and distance-based metrics:

* **Descriptive statistics**
* **Mann–Whitney U test**
* **Kolmogorov–Smirnov test**
* **Normalized Wasserstein distance**
* **Percentage of generated values within the natural 5th–95th percentile interval**

These analyses are performed at two levels:

* **Individual model level**
* **Generation-strategy level**

This allows both model-specific and broader methodological trends to be evaluated.

---

## ✅ Sequence Quality Control

To ensure consistent and reproducible physicochemical calculations, only sequences composed entirely of the **20 standard proteinogenic amino acids** are retained for quantitative analysis.

Sequences containing:

* non-canonical residues,
* unsupported amino-acid symbols, or
* otherwise invalid sequence characters

are **excluded from benchmarking in their entirety** and logged for traceability.

This quality-control step prevents invalid residues from introducing inconsistencies into property calculations.

---

## 🌿 Natural Reference Sets

Natural peptide reference sets contain **100 sequences per primary peptide category** and were derived from established peptide databases:

| Peptide Category              | Reference Database |
| ----------------------------- | ------------------ |
| Antimicrobial peptides        | **APD6**           |
| MHC-binding peptides          | **IEDB**           |
| Cyclic / macrocyclic peptides | **CycPeptMPDB**    |

Equal-sized reference subsets were used to provide a **standardized basis for comparison across peptide classes**.

## ▶️ Running the Notebook

The benchmarking notebook is designed primarily for use in **Google Colab**.

### Steps

1. Open `RL-Peptide-Property-Benchmarking.ipynb` in Google Colab.
2. Run the notebook cells sequentially.
3. Upload the requested FASTA files when prompted.
4. Allow the workflow to:

   * validate peptide sequences,
   * calculate physicochemical properties,
   * perform statistical analyses,
   * generate distribution plots,
   * rank models and generation strategies, and
   * export the final HTML benchmarking report.

> **FASTA header requirement:**
> For generated peptide datasets, FASTA headers should identify the **model** and **peptide type** according to the format expected by the notebook.

## 📊 Statistical Notes

Please consider the following points when interpreting the benchmarking results:

* Statistical tests are performed only for groups containing **at least three sequences**.
* Reported **p-values are unadjusted for multiple comparisons** and should therefore be interpreted as exploratory.
* Model-level comparisons represent the **available or reported generated sequence sets**, rather than complete model-output distributions.
* For cyclic peptides, sequence-based physicochemical calculations do **not explicitly model covalent cyclization, terminal modifications, or other structural constraints**.
